# Take-home assignments at Saaf Finance

This repository is the home for the take-home assignments we use when hiring at Saaf Finance. Each assignment lives in
its own folder, named after the role it's for.

| Role | Folder | The assignment |
|---|---|---|
| MLOps Engineer — AI Platform & Infrastructure | [`mlops-engineer/`](mlops-engineer/) | Make an AI agent survive production load and failures |

## For candidates

- Your recruiter will tell you which assignment is yours. Everything you need is in that folder: start with its README.
- Work only in your role's folder. The others are for other roles.
- Keep your solution private: share a private repository with us, or send a zip. Please don't fork this repository
  publicly.
- AI coding assistants are welcome unless an assignment says otherwise.

## Adding an assignment

- Create one folder per role, named after the role in lowercase with hyphens, e.g. `data-engineer/`.
- Make it self-contained: a README with the brief, and everything a candidate needs to run it from inside that folder.
- It must run on a laptop, without access to any company system.
- This repository is public. Never add internal names, systems or data, and keep reviewer notes, scoring guides and
  reference solutions out of it.
- Add a row to the table above.
